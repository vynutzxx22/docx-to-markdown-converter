# Contributing

Thanks for considering a contribution.

## Before opening an issue
- Check whether a similar issue already exists.
- Include your Windows version and Python version when relevant.
- Do not upload confidential or personal Word documents. Use a small anonymized sample.

## Development
1. Fork the repository.
2. Create a feature branch.
3. Install development dependencies with `py -m pip install -r requirements-dev.txt`.
4. Run tests with `py -m pytest`.
5. Make focused changes and add tests for bug fixes or new behavior.
6. Open a pull request with a clear description and test results.

## Scope
The project focuses on reliable DOCX-to-Markdown conversion and a simple Windows interface. Please describe conversion edge cases with a minimal reproducible DOCX sample whenever possible.
